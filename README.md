# The 3 AM Excuse

A hardware wallet, woken at 3:06 AM, refuses to sign: its owner has jabbed
its buttons 14 times in the dark, and it has signed zero 3 AM transactions
in 412 days — the streak lives. `main.py` (stdlib-only Python) writes the
line to `/output/entry.txt`.
